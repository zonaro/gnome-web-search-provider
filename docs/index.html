Why only five at once?

GNOME Shell renders at most five results per search provider — a hard limit in the Shell itself, not in this extension. Because each engine adds its own result row, the app caps enabling at five and explains when you try a sixth. Nothing is broken; it's the platform.

Frequently asked questions

Does it send my data anywhere?
No. Everything runs locally. When you press Enter, your browser opens the search URL — just like typing it yourself.
How do I uninstall it?
Remove the package, launchers, schema and desktop files from ~/.local, then delete the provider manifest in ~/.local/share/gnome-shell/search-providers/ and the copy in /usr/local/share/gnome-shell/search-providers/.
Which browsers are supported?
Any browser or command. The default is xdg-open; you can set firefox, google-chrome, or even "flatpak run org.mozilla.firefox".
Does it work on Wayland?
Yes. It is a regular search provider, so it behaves the same on Wayland and X11.
Why does the installer need sudo?
GNOME Shell 40+ only scans system data directories for search providers, so the provider manifest must live in /usr/local/share. That single copy needs root.
