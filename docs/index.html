Instale agora em 30 segundos

Um comando. Depois é só sair e entrar de novo. Sem compilar nada, sem dor de cabeça.

curl -fsSL https://raw.githubusercontent.com/zonaro/gnome-web-search-provider/master/install-local.sh | sh
  • 1. Cole o comando no terminal e aperte Enter.
  • 2. Saia e entre novamente (para o GNOME descobrir o buscador).
  • 3. Aperte Super, digite algo e escolha onde pesquisar. 🎉
Preciso ser root / usar sudo?

Não. O instalador usa sua pasta pessoal (~/.local). Ele só pede sudo uma vez para registrar o buscador no sistema — sem isso o GNOME não o enxerga.

Funciona na minha distro?

Se você usa GNOME Shell (Ubuntu, Fedora, Debian, Arch, Pop!_OS…), sim. Só precisa de Python 3.8+ — que já vem instalado.

É realmente grátis?

Sim, licença MIT, código aberto no GitHub. Sem conta, sem anúncios, sem rastreamento.
