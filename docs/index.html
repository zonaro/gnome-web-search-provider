AI entries: URL templates may prefill, require submit/sign-in

ChatGPT Search, Claude, Grok and Microsoft Copilot Search appear in Web Search above. Their URL templates may prefill your query, open standard search results, or require sign-in or submit — behavior varies by service and session. No end-to-end verification or forced AI/web mode; enable like any other engine, up to five at a time.

Kagi may show a sign-in wall; You.com works anonymously.

Why only five at once?

GNOME Shell renders at most five results per search provider — a hard limit in the Shell itself, not in this provider. Each engine adds its own result row, so the app caps enabling at five and explains when you try a sixth. Nothing is broken; it's the platform.

Frequently asked questions

Does it send my data anywhere?
When you press Enter, your browser opens the search URL — just like typing it yourself — so the destination engine receives your query. The provider itself doesn't run a backend or require an API key. The installer and preferences window may fetch site favicons (including from Google/DuckDuckGo icon services) for display; see favicons.py. Review the source for exact network behavior.
How is it different from my browser address bar?
It isn't a browser extension and doesn't touch your address bar. It adds search results to the GNOME Activities Overview (the Super key search box). Pressing Enter opens the chosen engine's results in your default browser.
Are ChatGPT, Claude, Grok and Copilot Search guaranteed web search?
No. Their URL templates may prefill your query, open standard search results, or require sign-in or submit — behavior varies by service and session. There's no end-to-end verification or forced AI/web mode. Use them like any other engine.
How do I uninstall it?
Run the one-line uninstaller: curl -fsSL https://raw.githubusercontent.com/zonaro/gnome-web-search-provider/master/uninstall.sh | sh. It removes the package, launchers, schema, desktop entries and the provider manifest from ~/.local and /usr/local. Append -s -- --purge to also delete your custom providers, settings and favicon cache. From a clone you can run sh uninstall.sh (or sh uninstall.sh --purge).
Which browsers are supported?
Any browser or command. The default is xdg-open; you can set firefox, google-chrome, or even "flatpak run org.mozilla.firefox".
Does it work on Wayland?
Yes. It is a regular search provider, so it behaves the same on Wayland and X11.
Why does the installer need sudo?
GNOME Shell 40+ only scans system data directories for search providers, so the provider manifest must live in /usr/local/share — that requires sudo. install-local.sh also uses sudo for legacy cleanup. Review install-local.sh for the exact sudo steps.
